`L2_Replacement` was confirmed explicitly set to `plru` before every app (it resets to
random on every FPGA reprogram — board state does not remember the build flag).

`simdev.runconf` args, `NTHREADS=1`). Script: `scripts/ssbc_scripts/run_parsec_session.exp`

### Script fix: `run_parsec_session.exp` missing-completion-signal bug

The version of `run_parsec_session.exp` found in `scripts/ssbc_scripts/` at the start of
this session (user flagged that directory as "polluted" by unrelated scripts) detected a
finished benchmark only by matching the shell prompt, with no confirmation that the child
process had actually printed its `workload rc=` line first. Rewrote it to require **both**
a `[SBC-WINDOW]` line and a `workload rc=` line via `exp_continue` before trusting a result
(failure modes: `NO_RC_SEEN` / `NO_WINDOW` / `SEND_FAIL` / `TIMEOUT`). Also added a `-policy`
flag so `L2_Replacement` is set explicitly every run instead of relying on whatever the FPGA
reset to. `fix_bodytrack.exp` (new, one-off) uses the same completion-detection pattern.
